# Results Directory

This directory stores all experiment outputs from the GPU global routing prototype (`router_lp/`).

## Experiment Matrix CSV

Files named `experiment_matrix_<YYYYMMDD_HHMMSS>.csv` are generated by:
```bash
bash scripts/run_experiment_matrix.sh
```

### CSV Column Reference

| Column | Description |
|--------|-------------|
| `benchmark` | Benchmark case name (from `benchmarks/local_suite_manifest.yaml`) |
| `mode` | Router mode: `lag_cpu`, `lag_gpu`, or `lag_gpu_polish` |
| `routed_nets` | Number of nets successfully routed |
| `disconnected` | Number of nets that remain disconnected after routing |
| `max_viol` | Maximum capacity violation (overflow) across all edges |
| `avg_viol` | Average capacity violation across violated edges |
| `total_time_s` | Total router wall-clock time in seconds |
| `wl_cost` | Wire-length cost reported by the evaluator |
| `via_cost` | Via cost reported by the evaluator |
| `overflow_cost` | Overflow/congestion cost reported by the evaluator |
| `open_nets` | Number of open (un-routed) nets per evaluator |
| `incompleted_nets` | Number of incompletely routed nets per evaluator |

Fields are set to `N/A` when the router or evaluator fails for a given (benchmark, mode) pair.

### Mode Definitions

| Mode | Flags | Description |
|------|-------|-------------|
| `lag_cpu` | `--mode lagrangian --lag-iters 50 --max-nets 50` | CPU Dijkstra Lagrangian routing |
| `lag_gpu` | `--mode lagrangian --lag-gpu --lag-iters 50 --max-nets 50` | GPU Bellman-Ford Lagrangian routing |
| `lag_gpu_polish` | `--mode lagrangian --lag-gpu --lag-iters 50 --max-nets 50 --lag-polish` | GPU BF + cuPDLPx hotspot polish (experimental) |

## Subdirectory Layout

```
results/
  baseline/           — InstantGR baseline routing outputs (per benchmark)
  experiment_matrix_*.csv  — per-run experiment summaries
  README.md           — this file
```

## Param Sweep CSVs

Files named `param_sweep_<timestamp>.csv` are generated by `scripts/run_param_sweep.sh`
and record metric sensitivity to individual hyperparameters (lag-step, lag-decay, etc.).

## Subgraph Study CSVs

Files named `subgraph_study_<timestamp>.csv` are generated by `scripts/run_subgraph_study.sh`
and record how routing quality scales with subgraph size (hotspot window radius, max-nets limit).
